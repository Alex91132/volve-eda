# Volve: анатомия месторождения — EDA

Разведочный анализ данных реального морфского месторождения **Volve**
(Equinor, Северное море; разработка 2008–2016, данные открыты в 2018).

Чем отличается от шаблонного EDA: анализ построен на **гипотезах**, а не на
«посмотрим на распределения». Каждый содержательный раздел заканчивается
статистической проверкой (тесты, доверительные интервалы, бутстреп) и
выводом, пригодным для решений по разработке.

## Данные

Суточные замеры 7 скважин основного фонда (5 добывающих, 2 нагнетательные;
F-1 C переведена из добычи в закачку): 15 634 строки × 24 колонки —
наработка, устьевые/забойные давления и температуры, штурвал, объёмы
нефти/газа/воды/закачки. Плюс месячная сводка и координаты скважин.

Источник: Equinor Volve field data (публичный датасет, зеркало выгрузки).

## Ключевые результаты

- **Качество данных**: пропуски датчиков до 64 % колонок, остановки до 41 %
  дней по скважинам; дубликатов и отрицательных объёмов нет.
- **Концентрация фонда**: две скважины (F-12 H, F-14 H) дают **85 %** всей нефти.
- **Перезапуски обходятся дороже, чем приносят**: после 113 эпизодов остановок
  дебит нефти в среднем ниже на 31 м³/сут (Wilcoxon p = 0.067, на границе
  значимости).
- **Заводнение**: медианная компенсация 1.12; связь закачки с добычей воды
  умеренная (Spearman ρ = 0.46, 95 % ДИ [0.25; 0.65] бутстрепом), с нефтью — слабее.
- **Decline флагмана F-12 H**: экспоненциальный спад D = 42 %/год
  (R² = 0.79, 95 % ДИ [38; 47] %/год).

## Структура

```
├── volve_eda.ipynb   # основной ноутбук с результатами (исполнен)
├── analysis.py       # исходник анализа в формате jupytext-ячеек (# %%)
├── make_notebook.py  # сборка analysis.py -> ipynb (воспроизводимость)
├── data/
│   ├── daily.csv     # суточная добыча, 15 634 строки
│   ├── monthly.csv   # месячная сводка
│   └── locations.csv # координаты скважин
└── requirements.txt
```

## Запуск

```bash
pip install -r requirements.txt
jupyter lab volve_eda.ipynb
# или пересобрать ноутбук из исходника и исполнить:
python make_notebook.py && jupyter nbconvert --to notebook --execute --inplace volve_eda.ipynb
```

## План трилогии

Это первый проект серии по данным Volve:

1. **EDA** (этот репозиторий) — качество данных, профиль добычи, гипотезы;
2. ML-прогноз дебита на месяц вперёд (бэктестинг без утечек);
3. Survival-анализ времени до обводнения (Каплан–Мейер, Кокс).
