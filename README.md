# Volve: анатомия месторождения — EDA

Разведочный анализ данных реального морского месторождения **Volve**
(Equinor, Северное море; разработка 2008–2016, данные открыты в 2018).

Чем отличается от шаблонного EDA: анализ построен на **гипотезах**, а не на
«посмотрим на распределения». Каждый содержательный раздел заканчивается
статистической проверкой (тесты, доверительные интервалы, бутстреп) и
выводом, пригодным для решений по разработке.

## Данные

Суточные замеры 7 скважин основного фонда (5 добывающих, 2 нагнетательные;
F-1 C переведена из добычи в закачку): 15 634 строки × 24 колонки —
наработка, устьевые/забойные давления и температуры, штуцер, объёмы
нефти/газа/воды/закачки. Плюс месячная сводка и координаты скважин.

Источник: Equinor Volve field data, [Equinor Open Data Licence](https://www.equinor.com/energy/volve-data-sharing).
Правообладатели — Equinor ASA и бывшие партнёры по лицензии Volve; данные распространяются
без права перепродажи и с указанием правообладателей.

## Ключевые результаты

- **Качество данных**: пропуски датчиков до 64 % колонок, остановки до 41 %
  дней по скважинам; дубликатов и отрицательных объёмов нет.
- **Концентрация фонда**: две скважины (F-12 H, F-14 H) дают **85 %** всей нефти.
- **Эффект перезапуска завышается вдвое, если не учесть падение добычи.** Наивное «до/после»
  по 111 остановкам: дебит после остановки ниже на 8 % (медиана). Но тот же расчёт в случайные
  дни *без* остановок (плацебо) даёт −2 % — это естественное падение. С поправкой на тренд
  эффект **−3,7 %**, 95 % ДИ бутстрепом по скважинам [−14,5; −0,1] %, и держится он на F-1 C
  (скважина на исходе добычи, позже переведённая под закачку). У F-12 H и F-14 H — около нуля.
- **Связь закачки с добычей воды — артефакт времени работы платформы.** Месячные объёмы
  коррелируют (ρ = 0,46; с нефтью даже сильнее), но часы работы добывающих и нагнетательных
  скважин меняются синхронно (ρ = 0,75 по изменениям). В дебитах на час работы связь
  закачки с водой ρ = 0,13. Обычный бутстреп для месячного ряда дал интервал [0,26; 0,64],
  блочный (с учётом автокорреляции) — [0,01; 0,76].
- **Decline флагмана F-12 H**: номинальный темп D = 42 %/год (дебит падает на треть за год),
  R² = 0,79. Остатки сильно автокоррелированы (Durbin — Watson 0,26), поэтому интервал —
  Ньюи — Уэст: [32; 53] %/год вместо [38; 47] у обычного МНК.

## Чему учит этот EDA

Две из трёх «находок» первой версии анализа не пережили проверки. «Перезапуски обходятся
дороже» — это сравнение «до/после» без контрольной группы, в которое попало естественное падение
добычи. «Связь закачки с водой» — общая причина (простои платформы), а интервал был занижен
бутстрепом, который не учитывает автокорреляцию. Ровно эти ловушки — «до/после» и общая
причина — разобраны на синтетике с известной истиной в проекте
[gtm-causal-inference](https://github.com/Alex91132/gtm-causal-inference).

## Структура

```
├── volve_eda.ipynb   # основной ноутбук с результатами (исполнен)
├── analysis.py       # исходник анализа в формате jupytext-ячеек (# %%)
├── make_notebook.py  # сборка analysis.py -> ipynb (воспроизводимость)
├── data/
│   ├── daily.csv     # суточная добыча, 15 634 строки

└── requirements.txt
```

## Запуск

```bash
pip install -r requirements.txt
jupyter lab volve_eda.ipynb                       # или без установки: https://nbviewer.org/github/Alex91132/volve-eda/blob/main/volve_eda.ipynb
# или пересобрать ноутбук из исходника и исполнить:
python make_notebook.py && jupyter nbconvert --to notebook --execute --inplace volve_eda.ipynb
```

## План трилогии

Это первый проект серии по данным Volve:

1. **EDA** (этот репозиторий) — качество данных, профиль добычи, гипотезы;
2. ML-прогноз дебита на месяц вперёд (бэктестинг без утечек);
3. Survival-анализ времени до обводнения (Каплан–Мейер, Кокс).
